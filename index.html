Applied Machine Learning Portfolio

End-to-end Machine Learning and Deep Learning solutions covering tabular regression, pipeline classification, multi-class NLP, and audio classification. Each project emphasizes real-world constraints, rigorous evaluation, and leak-free feature pipelines.

Methodology & Standards

All tabular pipelines are constructed using strict ColumnTransformer and Pipeline encapsulations to guarantee zero data contamination between training folds and validation sets. Hyperparameters are validated via stratified cross-validation.

Featured Projects

Project 01: Real Estate Price Regression

Objective: Predict real estate prices from multi-modal tabular data.

Validation Metric: Log-RMSE: 0.3105

Weighted blend of Ridge (0.2) + LightGBM (0.4) + CatBoost (0.4). Implements log-transform target normalization to stabilize skewed price distributions alongside complementary gradient boosted and linear estimators.

Project 02: Hotel Cancellation Prediction

Objective: Predict booking cancellations with production-style pipelines.

Architecture: Scikit-learn Pipeline + StackingClassifier

Built leak-free preprocessing with ColumnTransformer. Engineered domain features including total nights, party size, price ratios, and seasonal calendar signals with probability threshold calibration.

Project 03: NLP Sentiment Analysis

Objective: Multi-class sentiment classification from short text.

Performance: ~65% macro accuracy

Hybrid word (1–3 grams) and sub-word character (3–6 grams) extraction assembled via FeatureUnion. Formulates a stacked ensemble utilizing LinearSVC, LogisticRegression, and Naive Bayes for robust text classification.

Project 04: Imbalanced Comment Classification

Objective: Large-scale multiclass text classification under severe class imbalance.

Scale: 200,000+ samples

Stratified cross-validation, sparse matrix computation using scipy.sparse.csr_matrix, and GPU acceleration via RAPIDS cuML. Utilizes calibrated probability thresholds to accurately detect minority classes.
